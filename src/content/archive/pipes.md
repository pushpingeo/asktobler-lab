A few people are posting on their first attempts at using ‘[Pipes](https://web.archive.org/web/2007/http://pipes.yahoo.com/)’ – the latest web offering from Yahoo. Pipes provides an online, user friendly GUI, to mix and match RSS data – the name of the service pays tribute to Unix pipes. I played around a little with it at the weekend and am impressed. [Mikal](https://web.archive.org/web/2007/http://brainoff.com/weblog/2007/02/12/1228) has documented his attempt to generate a GeoRSS feed which locates any blogs that are discussing a particular [technorati](https://web.archive.org/web/2007/http://technorati.com/) tag…he also contemplates some of the functionality Pipes might embrace in the future.

One thing I’d really like Pipes (or a similar service) to offer is a web based graphical interface with code behind that best guesses the XSL file required to get from one flavour of XML to another, or allows the user to match elements in each of the XML files in a ‘drag and drop’ fashion. Maybe it’s already out there and I haven’t found it? I think it would be really useful service, especially for people who don’t work with XML and XPath on a daily basis, helping to transform XML datasets into a format they can use.
